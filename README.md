# Coaching Tremplin — Site web

Site vitrine pour **Christelle Tournier**, coach professionnelle.

## Déploiement sur GitHub Pages

1. Crée un dépôt GitHub nommé `christelle-tournier.github.io`
   *(ou `coaching-tremplin` → accessible via `tonpseudo.github.io/coaching-tremplin`)*

2. Upload tous les fichiers (index.html, css/, js/)

3. Va dans **Settings > Pages** et sélectionne la branche `main`

4. ✅ Le site sera en ligne en 2 minutes

## Personnalisation

- **Photo** : remplace la placeholder dans `#about` par une vraie photo
- **Téléphone** : ajoute le numéro dans la section Contact
- **Couleurs** : modifie les variables CSS dans `:root` (coral, sage, dark, light)
